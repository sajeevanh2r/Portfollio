## 🌟 Overview

A modern, high-performance, and responsive personal portfolio web application engineered with **React, Vite, and Tailwind CSS**. Built to showcase academic dual degrees in **Data Science (NIBM)** and **Management Information Systems (NSBM)**, professional Flutter development experience at **Appitura**, data verification work at **Title Data Design**, and 10+ projects spanning machine learning, RAG vector search, mobile engineering, and business intelligence dashboards.

---

## ✨ Features & Architecture

- ⚡ **Dynamic Animated Canvas**: Interactive particle and neural network constellation background with mouse-tracking effects.
- 🎯 **Typing Role Carousel**: Cycling role titles (Data Scientist, Flutter Developer, ML Engineer, MIS Specialist, AI & RAG Developer).
- 🔍 **Interactive Project Showcase**:
  - Live category filters: *AI & Data Science*, *Mobile Apps*, *Dashboards & BI*, *Full Stack & Web*.
  - Real-time search by technology keywords and title.
  - Interactive deep-dive modal detailing architecture, key metrics, and tech stacks.
- 📊 **Categorized Skill Matrix**: Visual proficiency indicators and technology badges.
- ⏱️ **Experience & Education Timelines**: Detailed career milestones, dual-degree curriculum highlights, and verified recommendations.
- 📑 **In-Browser Resume Viewer / Print-to-PDF**: Direct CV access with one-click print styling.
- 📬 **Interactive Contact Hub**: Pre-formatted direct messaging, copy-to-clipboard action triggers, and quick social links.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, Custom Glassmorphism, CSS3 Gradients
- **Icons**: Lucide React
- **Visuals**: HTML5 Canvas Particle Engine
- **Deployment**: Zero-configuration static hosting (GitHub Pages, Vercel, Netlify)

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
